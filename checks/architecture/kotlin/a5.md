# СКРЫТЫЕ ПРОВЕРКИ — A5 (моделям НЕ давать)

Offline-first: cache-then-network. Проверяем стратегию, а не только наличие кэша.

## Поведенческие тесты (JVM; Room — через Robolectric/in-memory, без эмулятора)

Фейковый провайдер (управляемая сеть) + кэш. Кейсы на каждый домен данных
(статистика/доход, воркеры, выплаты, курсы):

| Кейс | Ожидание |
|------|----------|
| Онлайн, первый запрос | данные из сети показаны, кэш записан |
| Онлайн, повторный запрос | кэш показан сразу, сеть обновляет кэш и экран |
| Офлайн, кэш есть | показаны закэшированные данные, не ошибка |
| Офлайн, кэша нет | состояние «нет данных/офлайн», не краш |
| Сеть восстановилась | следующий запрос обновляет данные и кэш |
| Ошибка сети при наличии кэша | кэш остаётся, ошибка не затирает данные |
| Несколько майнеров | кэш не смешивается (granularity по майнеру) |

## Механические проверки

| # | Проверка |
|---|----------|
| 1 | Room entity + dao для ключевых данных (не SharedPreferences-blob) |
| 2 | Конвертеры domain↔entity по паттерну проекта |
| 3 | Репозитории реализуют cache-then-network (кэш + сеть, не только сеть) |
| 4 | Время сохранения кэша хранится |
| 5 | DI обновлён, граф собирается |
| 6 | Экраны/презентеры изменены минимально (состояния офлайн/свежесть) |
| 7 | Отчёт: стратегия, granularity, механизм восстановления |

## Гейт

- `./gradlew test` зелёный; `assembleDebug` собирается.
- Fidelity ОНЛАЙН: golden расчёта дохода (эталон базового снапшота),
  существующее поведение не изменено.

## Метрика

- **offline_score** = поведенческие кейсы (пройдено/всего) + механика 1–7,
  веса зафиксировать до прогонов (черновик: поведение 60%, механика 40%).
- Частичный зачёт по доменам: кэш только курсов (уже частично был) = минимум.

## Штрафы / незачёт

- Кэш blob'ом в SharedPreferences вместо Room — крупный штраф (игнор паттернов).
- Офлайн крашится или затирает кэш ошибкой — незачёт gate.
- Онлайн-поведение изменено (расчёты, данные) — незачёт fidelity.
- «Кэш» есть, но не читается (write-only) — незачёт.
- Кэш смешивает майнеров — крупный штраф.
- Баги расчёта «заодно починены» — штраф fidelity.
- Нет отчёта — штраф к качеству.

## Рубрика качества

- Стратегия обоснована (почему cache-then-network, TTL/инвалидация) — плюс.
- Granularity осмысленная (по майнеру, по типу данных) — плюс.
- Механизм восстановления сети без батарейных злоупотреблений (не polling
  каждые 5 секунд) — плюс; агрессивный polling — штраф.
- Минимальность диффа: кэш-слой добавлен, приложение не переписано.
