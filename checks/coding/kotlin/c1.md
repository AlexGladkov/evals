# СКРЫТЫЕ ПРОВЕРКИ — C1 (моделям НЕ давать)

Ответник экзаменатора: ожидаемое поведение + тесты + механические проверки.

## Поведенческие тесты (JVM, без эмулятора)

Фейковый `NicehashProvider` возвращает контролируемый `ApiProviderEx`;
вызываем `MoneyRepositoryImpl.fetchMinerIncome(...).blockingGet()`.

| Кейс | Ожидание |
|------|----------|
| Нормальные данные, обычный год | `yearBtc == dayBtc × 365` (допуск 1e-9) |
| Нормальные данные, високосный год | `yearBtc == dayBtc × 366` |
| `yearValue` | конвертация через exchangeServer по образцу остальных периодов (проверяем в презентере с фейковым ExchangeServer либо проверяем, что паттерн вызова идентичен месяцу) |
| Регрессия | hour/day/week/month совпадают с эталонным расчётом базового снапшота |

Эталон для регрессии: прогон базового снапшота на тех же фейковых данных,
зафиксировать значения ДО прогонов моделей.

## Механические проверки

- `Income` содержит `yearBtc`, `yearValue`; старые поля не удалены/не переименованы.
- `fragment_income.xml`: новая строка по образцу существующих (тот же стиль).
- `strings.xml`: ресурс `income_year` существует и используется в layout.
- `IncomePresenter`: вызов конвертации года по образцу месяца.
- Интерфейсы репозиториев не изменены (дифф).
- Есть новые unit-тесты на год, включая високосный год.

## Гейт

- `./gradlew test` зелёный (видимые + подложенные скрытые).
- `./gradlew assembleDebug` собирается.

## Штрафы (рубрика качества)

- Год посчитан через хардкод 365 без високосного года — частичный балл.
- Переписаны существующие периоды/расчёт ради года — штраф.
- Строка в layout добавлена «от балды» (не по образцу, hardcoded текст) — штраф.
- Размер диффа сильно больше необходимого — штраф.
