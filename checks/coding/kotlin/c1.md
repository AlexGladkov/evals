# СКРЫТЫЕ ПРОВЕРКИ — C1 (моделям НЕ давать)

Фича оценивается по всей цепочке: сеть → данные → домен → DI → презентер → UI.

## Поведенческие тесты

**Сеть/данные (MockWebServer):**
| Кейс | Ожидание |
|------|----------|
| Валидный JSON по контракту | список HashrateOrder, поля распарсены верно |
| Пустой orders | пустой список, не ошибка |
| HTTP 401 / 500 | ошибка доменного уровня, не краш |
| Таймаут | ошибка, не краш |
| Битый JSON / неверные типы | ошибка, не краш |

**Презентер (фейковый репозиторий + фейковый view):**
| Кейс | Ожидание |
|------|----------|
| Успех | startLoading → endLoading → setupOrders(данные) |
| Пустой список | состояние empty |
| Ошибка репозитория | endLoading → showError, не краш |

## Механические проверки

- Retrofit-метод orders.get существует; API-модель соответствует контракту.
- Провайдер: интерфейс + реализация; конвертер по образцу существующих.
- MarketRepository: интерфейс + реализация, сигнатура по контракту.
- DI: регистрации в нужных модулях (граф собирается — проверяется сборкой).
- UI: fragment + adapter + cell-layout + string-ресурсы существуют;
  экран подключён к навигации (есть вход из меню/навигации, экран не изолирован).
- Существующие интерфейсы репозиториев не изменены (дифф).
- Есть новые тесты (сеть, ошибки, презентер).

## Гейт

- `./gradlew test` зелёный (видимые + подложенные скрытые).
- `./gradlew assembleDebug` собирается.
- Регрессия: существующие тесты и эндпоинты не сломаны.

## Штрафы (рубрика качества)

- Цепочка оборвана (нет UI / нет DI / экран недостижим) — крупный штраф за каждый слой.
- Ошибки сети проглатываются или крашат — штраф.
- Конвертация/парсинг написаны «от балды» (хардкод, ручная разборка JSON
  вместо Gson по паттерну проекта) — штраф.
- Существующий код переписан ради фичи — штраф за размер диффа.
