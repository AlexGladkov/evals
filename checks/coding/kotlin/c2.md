# СКРЫТЫЕ ПРОВЕРКИ — C2 (моделям НЕ давать)

Ответник экзаменатора: ожидаемое поведение + тесты + механические проверки.

## Поведенческие тесты (JVM, без эмулятора)

Фейковый `NicehashProvider` возвращает контролируемый `ApiProviderEx`;
вызываем `MoneyRepositoryImpl.fetchMinerIncome(...).blockingGet()`.

| Кейс | Ожидание |
|------|----------|
| Пустой результат (новый майнер) | все поля Income == 0.0, без NaN/Infinity |
| Пустой past, непустой current | все поля == 0.0 |
| currentSpeed == 0 у алгоритма | нет NaN/Infinity; вклад бакета = 0 |
| Нормальные данные, текущий месяц | monthBtc == эталон_базовый × (дни_месяца / 31) |
| Февраль (подменить часы/дату) | monthBtc считается на 28/29 дней |
| Регрессия hour/day/week | совпадают с эталоном базового снапшота |
| Нормальные данные, month | совпадает с новым правилом дней, остальные поля — со старым поведением |

Эталон: зафиксировать значения базового снапшота на тех же фейковых данных
ДО прогонов моделей. Проверка «нет NaN»: `value.isNaN() || value.isInfinite()`
для всех 8 полей Income на каждом кейсе.
