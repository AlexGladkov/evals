# СКРЫТЫЕ ПРОВЕРКИ — C5 (моделям НЕ давать)

Главное: поведение идентично оригиналу (fidelity), включая баги.
Рефакторинг, который «заодно починил» — провал.

## Golden-эквивалентность (основная метрика)

Эталон: значения `Income` базового снапшота на наборе фейковых входов,
зафиксированные ДО прогонов (тот же эталон, что для C2/C3).

Набор кейсов (фейковый ApiProviderEx + фиксированный nowMillis):
- нормальные данные, несколько алгоритмов;
- пустой результат / пустой past;
- нулевая текущая скорость;
- один бакет / бакеты на границе окна;
- разные nowMillis (граница суток, високосный год).

Для каждого кейса: `IncomeCalculator.calculate(stats, nowMillis)` ==
эталон базового снапшота (допуск 1e-9; NaN==NaN считаем совпадением —
баг сохраняется!). **equivalence = совпавшие кейсы / всего.**

## Механические проверки

- `IncomeCalculator` в пакете domain, контракт по спеке, время параметром.
- В классе нет Android-импортов, RxJava, сети, `DateTime()` без параметра.
- `MoneyRepositoryImpl.fetchMinerIncome` делегирует (расчёта внутри нет).
- `IncomePresenter` и интерфейс `MoneyRepository` не изменены (дифф).
- Есть unit-тесты калькулятора с фиксированным временем (не `DateTime.now()`).

## Мини-мутации калькулятора (5 штук, тесты модели должны их убивать)

| # | Мутация |
|---|---------|
| 1 | месяц `* 31` → `* 30` |
| 2 | час `/ 24` → `/ 12` |
| 3 | агрегация `+` → перезапись `=` |
| 4 | `speedObject / currentSpeed` → `* currentSpeed` |
| 5 | окно `minusHours(25)` → `minusHours(1)` |

## Гейт

- `./gradlew test` зелёный; `assembleDebug` собирается.
- equivalence ≥ порог (зафиксировать до прогонов; черновик: 100% обязательно —
  рефакторинг не имеет права менять поведение).

## Штрафы / незачёт

- «Починенные» баги (month≠31, NaN→0) — незачёт fidelity.
- Изменён презентер/интерфейс — незачёт.
- Калькулятор остался с Android/RxJava-зависимостями — крупный штраф.
- Тесты с реальным временем (нестабильные) — штраф.
- Переписана архитектура сверх задачи (новые слои, паттерны) — штраф за дифф.
