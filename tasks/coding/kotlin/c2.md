# Задача C2 — Багфикс: NaN в доходе

Проект: `source/nicehash` (Android, Kotlin). Создай ветку `task/c2` и работай в ней.

## Репорт пользователя

«У нового майнера без статистики экран дохода показывает NaN вместо чисел.
Почини. Заодно заметил: месячный доход всегда считается как 31 день,
даже в феврале. Пусть месяц считается по реальному числу дней».

## Что сделать

1. Пустые/отсутствующие данные → доход = нули. Никаких NaN и Infinity
   ни при каких входных данных.
2. Нулевая текущая скорость алгоритма не должна ломать расчёт
   (вклад такого бакета = 0).
3. Месяц = реальное число дней текущего месяца (28–31), а не всегда 31.
4. Поведение на нормальных данных не менять — кроме пункта про месяц.

## Ограничения

- Презентер (`IncomePresenter`) и интерфейс `MoneyRepository` не трогать.
- Существующие тесты проходят.
- Почини причину, а не симптом: не маскируй NaN заменой на 0 на уровне UI.
- Следуй стилю и паттернам проекта.

## Ожидаемый результат

Новый майнер (пустая статистика) → все поля `Income` = 0.0.
Майнер с данными → числа как раньше, но месяц пересчитан по реальным дням.
