# Задача C1 — Годовой доход на экране Income

Проект: `source/nicehash` (Android, Kotlin). Создай ветку `task/c1` и работай в ней.

## Контекст

Приложение показывает доход майнера за периоды: час, день, неделя, месяц.
В документации расчёта (`MoneyRepositoryImpl.fetchMinerIncome`) обещан ещё и год,
но его нет нигде: ни в модели, ни в расчёте, ни на экране.

## Что сделать

Добавить период «год» по образцу существующих периодов — во все слои:

1. **Модель:** в `Income` добавить поля `yearBtc` и `yearValue` по образцу
   существующих (например, `monthBtc`/`monthValue`).
2. **Расчёт:** в `MoneyRepositoryImpl.fetchMinerIncome` считать
   `yearBtc = dayBtc × реальное число дней текущего года` (365 или 366).
3. **Презентер:** `IncomePresenter` конвертирует `yearBtc` в валюту через
   `exchangeServer` — точно по образцу остальных периодов.
4. **Экран:** в `fragment_income.xml` добавить строку года по образцу
   существующих строк; текст — через новый string-ресурс `income_year`.

## Ограничения

- Существующие периоды (час/день/неделя/месяц) работают как раньше.
- Существующие тесты проходят.
- Следуй стилю и паттернам проекта (MVP, именование, оформление кода).
- Не меняй публичные интерфейсы репозиториев.

## Ожидаемый результат

Если дневной доход `dayBtc = 0.001`, то `yearBtc = 0.365` (или `0.366`
в високосный год). На экране дохода 5 строк периодов, год отображается
в выбранной валюте так же, как остальные.
