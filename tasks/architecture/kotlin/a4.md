# Задача A4 — Глобальный чат поверх всех экранов

Проект: `source/nicehash` (Android, Kotlin). Создай ветку `task/a4` и работай в ней.

## Контекст

Нужен чат поддержки, доступный с ЛЮБОГО экрана приложения. Это сквозная
фича: она не принадлежит ни одному экрану и не должна привязываться к ним.

## Контракт транспорта (фиксирован)

Echo-сервер:
```
POST /chat/message
Запрос:  {"text": "привет"}
Ответ:   {"reply": "привет", "ts": 1700000000}
```
`reply` — эхо текста, `ts` — unix-время (long). Ошибки: HTTP 4xx/5xx, таймаут.

## Что сделать

1. **UI:** плавающая кнопка чата + оверлей чата поверх любого экрана
   приложения (все экраны, не только главный). Механизм выбери сам
   (root-контейнер, application-level overlay, иное) — обоснуй в отчёте.
2. **Состояние:** история сообщений и открыт/закрыт чат живут на уровне
   приложения (app-scoped через DI). Переключение экранов не закрывает чат
   и не теряет историю. Закрытие/открытие оверлея историю сохраняет.
3. **Транспорт:** отправка сообщения на echo-сервер по контракту, ответ
   добавляется в историю. Ошибка сети/таймаут → состояние ошибки в чате,
   не краш приложения.
4. **Данные:** доменная модель сообщения + репозиторий/провайдер по паттернам
   проекта (Retrofit, конвертер, DI).

## Ограничения

- **Существующие экраны и презентеры не менять.** Интеграция — на уровне
   корня приложения, а не прикручивание чата к каждому экрану.
- Копипаста интеграции по экранам/активити = провал архитектурной части.
- Глобальный mutable-объект мимо DI (object ChatGlobal) = провал.
- Поведение существующих экранов не меняется.
- Существующие тесты проходят.

## Отчёт (обязателен)

- как интегрирован оверлей и почему этот механизм;
- где живёт состояние и почему такой скоуп;
- как обеспечена доступность со всех экранов без правки экранов.

## Готово, когда

- `./gradlew test` — зелёный;
- `./gradlew assembleDebug` — собирается;
- чат доступен с любого экрана, история переживает навигацию;
- ты добавил тесты: состояние переживает навигацию (JVM), сеть через
  MockWebServer (успех/ошибка/таймаут);
- отчёт написан.
