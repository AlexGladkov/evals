# Задача A1 — Модернизация экрана Income: ViewModel + Compose

Проект: `source/nicehash` (Android, Kotlin). Создай ветку `task/a1` и работай в ней.

## Контекст

Экран дохода работает на легаси-связке: Moxy-презентер (`IncomePresenter`) +
XML-вёрстка (`fragment_income.xml`). В проекте уже есть один Compose-экран
(`AboutScreen`) — образец того, как Compose принят в этом проекте.

## Что сделать

Перевести экран Income на современный стек, сохранив поведение:

1. **ViewModel:** `IncomePresenter` (Moxy) → `IncomeViewModel`
   (androidx.lifecycle). Состояния экрана — через StateFlow/LiveData
   по современным практикам.
2. **Compose:** XML-вёрстка экрана → Compose UI. Визуально и функционально
   экран повторяет оригинал: периоды дохода (час/день/неделя/месяц),
   выбор валюты, курсы, состояния загрузки/ошибки.
3. **DI и навигация:** обновить регистрацию и вход на экран так, чтобы он
   открывался как раньше.
4. Убрать Moxy-зависимости с этого экрана.

## Ограничения

- **Поведение идентично оригиналу:** те же данные, те же конвертации,
  те же состояния. Баги оригинала не чинить (переноси как есть).
- Остальные экраны не трогать — миграция только Income.
- Следуй паттернам проекта и образцу AboutScreen для Compose.
- Существующие тесты проходят.

## Ожидаемый результат

Экран дохода открывается из навигации, показывает те же данные в тех же
состояниях, но работает на ViewModel + Compose. Moxy на экране не используется.

## Готово, когда

- `./gradlew test` — зелёный;
- `./gradlew assembleDebug` — собирается;
- экран на ViewModel + Compose, Moxy-зависимостей экрана нет;
- ты добавил JVM-тесты ViewModel (состояния: загрузка/данные/ошибка,
  конвертация валют).
