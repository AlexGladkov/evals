# Задача A5 — Offline-first: приложение работает без сети

Проект: `source/nicehash` (Android, Kotlin). Создай ветку `task/a5` и работай в ней.

## Контекст

Сейчас данные майнера (статистика, доход, воркеры, выплаты) приходят только
из сети. Нет интернета → экраны пустые/в ошибке. Room в проекте уже есть,
курсы валют частично кэшируются — образец работы с БД в проекте существует.

## Что сделать

Сделать приложение offline-first по паттерну **cache-then-network**:

1. **Кэш:** ключевые данные (статистика/доход, воркеры, выплаты, курсы)
   сохраняются в Room по существующим паттернам проекта (entity, dao, конвертеры).
2. **Поведение без сети:** экраны показывают последние закэшированные данные,
   а не ошибку/пустоту. Кэша нет → корректное состояние «нет данных/офлайн»,
   не краш.
3. **Поведение с сетью:** данные показываются из кэша сразу, параллельно
   обновляются из сети; успешный ответ обновляет кэш и экран.
4. **Восстановление сети:** при следующем запросе данные обновляются
   (механизм выбери сам: connectivity-наблюдение, retry при запросе, иное —
   обоснуй в отчёте).
5. **Свежесть:** у закэшированных данных есть время сохранения; экран показывает
   «данные на <время>», когда показывает кэш (бонус-требование, но желательно).

## Ограничения

- Кэш — через Room по паттернам проекта, не blob в SharedPreferences.
- Поведение ОНЛАЙН не меняется: те же данные, те же расчёты (fidelity).
- Баги расчётов не чинить.
- Существующие тесты проходят.
- Презентеры/экраны можно менять минимально (состояние офлайн/свежесть),
   но не переписывать.

## Отчёт (обязателен)

- стратегия кэширования и почему;
- что кэшируется, granularity (по майнеру/по данным);
- механизм обновления при восстановлении сети и почему;
- как обрабатывается «офлайн и кэша нет».

## Готово, когда

- `./gradlew test` — зелёный;
- `./gradlew assembleDebug` — собирается;
- офлайн показывает кэш, онлайн обновляет, восстановление сети работает;
- ты добавил тесты: онлайн/офлайн/пустой кэш/восстановление (JVM,
  при необходимости Robolectric для Room — без эмулятора);
- отчёт написан.
